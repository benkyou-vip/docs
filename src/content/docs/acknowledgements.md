本指南没有发明任何新东西，没有下面这些伟大的开源项目，就没有这份指南。

## 项目列表

| 项目 | 仓库 | 许可证 | 在本指南中的角色 |
| ---- | ---- | ------ | ---------------- |
| [Anki](https://apps.ankiweb.net) | [ankitects/anki](https://github.com/ankitects/anki) | AGPL-3.0 | 记忆的中枢，所有卡片由它调度复习（[Anki 与 SRS](/guides/anki-srs/)） |
| [Yomitan](https://yomitan.wiki) | [yomidevs/yomitan](https://github.com/yomidevs/yomitan) | GPL-3.0 | 浏览器划词词典，阅读时查词与制卡（[Yomitan 划词词典](/guides/yomitan/)） |
| [Lapis](https://github.com/donkuri/lapis) | [donkuri/lapis](https://github.com/donkuri/lapis) | GPL-3.0 | 挖句笔记类型（卡片模板），出自 donkuri 团队 |
| [mpv](https://mpv.io) | [mpv-player/mpv](https://github.com/mpv-player/mpv) | GPL-2.0+ | 高度可定制的命令行媒体播放器，沉浸式看片的主力 |
| [mpvacious](https://github.com/Ajatt-Tools/mpvacious) | [Ajatt-Tools/mpvacious](https://github.com/Ajatt-Tools/mpvacious) | GPL-3.0 | mpv 制卡脚本，看视频时一键挖句进 Anki（[mpv 播放器与 mpvacious 制卡](/guides/mpv/)） |

此外还要感谢这些项目的「上游」与生态：Yomitan 是 [Yomichan](https://github.com/FooSoft/yomichan) 停止维护后的社区续作；mpvacious 的思路源自经典的 subs2srs；AnkiConnect、FSRS 调度算法等插件与工具，也让这条工具链真正连了起来。

## 支持它们

如果你用这套流程学到了东西，欢迎回馈这些项目：

- 在 GitHub 上给仓库点一个 Star，帮助更多人发现它们；
- 报告 bug、提交改进，或参与文档与界面翻译；
- 按各项目页面提供的方式捐赠——很多作者维护这些工具已经很多年。

开源社区的最小回报方式很简单：**把工具用起来，并把方法分享给下一个人。**
