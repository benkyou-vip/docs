Yomitan 是沉浸式阅读体验的分水岭：没有它，查一个词要选中、复制、切窗口、粘贴、读释义，一分钟就过去了；有了它，按住键悬停即出释义，一秒搞定。查词的摩擦足够小，你才真的会去查。

> [!NOTE]
> 本篇以**英语学习**为例。Yomitan 本身语言无关——换一门语言，变化主要在**安装哪些词典**，详见下方[词典管理](#词典管理)。

## Yomitan 是什么

Yomitan 是 Yomichan 的社区维护继任者（原项目停止维护后由 TheMoeWay 社区接手），一个开源的浏览器划词词典扩展：

- 按住快捷键悬停单词，立刻弹出词典释义
- 词典本地存储、本地检索，无需联网查询
- 支持多本词典同时显示、自动还原词形变化（复数、时态等）
- 可以直接把词条 + 例句发送到 Anki（配合 AnkiConnect）

项目主页：[github.com/themoeway/yomitan](https://github.com/themoeway/yomitan)

## 安装

在 Chrome / Edge / Firefox 的扩展商店搜索 "Yomitan"，或从[项目仓库](https://github.com/themoeway/yomitan)的安装链接进入商店页面安装。

> [!TIP]
> 建议把扩展固定（pin）到浏览器工具栏，方便查看开关状态和快速进入设置。

## 上手使用

1. 打开任意英文网页（或电子书阅读网页）。
2. **按住 `Shift` 键，把鼠标悬停在单词上**——弹出词典窗口，展示该词在各本词典中的释义。
3. 悬停前**先用鼠标选中一段文字**，则可以对短语或整句查词。
4. 弹窗内可以翻页查看多个候选词条，也可以点击句中的其他词继续深挖（弹窗套弹窗）。

> [!TIP]
> 遇到 `went`、`larger` 这类变形词不用先还原原形——Yomitan 会自动尝试还原后再查，具体效果取决于词典与语言设置。

## 基础设置

进入扩展设置页（工具栏图标 → 齿轮），值得先看这几处：

- **扫描（Scanning）**：扫描触发键（默认 `Shift`，可换 `Alt` 等）、是否悬停自动弹窗、选中文字后是否立即扫描。
- **弹窗（Popup）**：窗口大小、停留时间、深色主题。
- **音频（Audio）**：配置朗读来源，可以在弹窗里播放单词读音。

设置项很多，但默认值已经可用，先跑起来再慢慢调。

## 词典管理

安装词典的通用步骤：

1. 下载词典包（zip 格式，不需要解压）。
2. 进入 Yomitan 设置 → **词典（Dictionaries）** → **导入（Import）**，选择 zip 文件。
3. 在「弹窗词典」列表中启用/排序刚导入的词典。

### 推荐词典（英语）

四本经典学习者词典：前三本是**英英释义词典**，任选其一作主力（或并存对照）；Oxford Collocations 是**搭配词典**，作补充。均有社区维护的 Yomitan 格式转换版本，下载链接见下方（待补全）。

#### Collins COBUILD Advanced Learner's Dictionary（第 10 版，COBUILD10）

- 招牌特色是**整句式释义**：用完整句子解释词义（"If a situation is bleak, it is ..."），释义本身就是用法示范，但篇幅较长。
- 例句取自 Collins 语料库的真实语料，地道且贴合当代用法。
- 词条带语料库词频分级（◆ 标记），高频词一目了然。
- 适合喜欢「在语境中理解词义」、想顺带积累句型的读者。

#### Longman Dictionary of Contemporary English（第 5 版，LDOCE5）

- 释义只使用约 2000 个最基础的英语词，是公认**对初学者最友好**的英英词典，从双语词典过渡到全英解释的舒适落脚点。
- 标注 Longman Communication 3000 高频词：S1–S3（口语）、W1–W3（书面语）分级。
- 例句丰富，格式清爽，转换版在 Yomitan 弹窗里显示效果很好。
- 英英入门的第一选择。

#### Oxford Advanced Learner's Dictionary（第 10 版，OALD10）

- 历史最悠久的学习者词典品牌，编纂严谨、内容全面。
- **Oxford 3000 / 5000 核心词体系**：按 CEFR 等级（A1–C1）标注，方便按水平筛选优先掌握的词。
- 用法注释丰富：同义词辨析、动词句型、搭配提示等。
- 适合与阶段化目标（分级阅读、备考）结合的读者。

#### Oxford Collocations Dictionary

- 定位不同：不是释义词典，而是**搭配词典**——告诉你一个词「通常和哪些词一起用」。按词性分类列出常见搭配（动词+名词、形容词+名词、介词短语等），加粗标出最高频组合。
- 对**输出**价值极大：写作、口语中避免 "strong rain" 式的别扭搭配。
- 建议常驻弹窗作第二词典：查生词时顺手看一眼搭配，对词的理解会立体很多。

#### 组合建议

- 主力释义词典三选一：偏好语境和例句选 COBUILD，想要最平易的解释选 LDOCE，喜欢分级体系选 OALD。
- 无论主力是谁，Oxford Collocations 都值得挂上。
- 弹窗词典排序：主力在前、搭配词典随后，一次弹太多内容会拖慢阅读节奏。

## 与 Anki 联动（进阶）

如果你的阅读环境在浏览器里，可以让 Yomitan 直接制卡，而不必手动复制粘贴。

**前置条件**：

1. 安装桌面版 Anki 并保持运行；
2. 安装 [AnkiConnect](/guides/anki-srs/#ankiconnect) 插件（代码 2055492159）。

**配置**：Yomitan 设置 → **Anki**：

1. 选择牌组和笔记类型；
2. 把 Anki 笔记类型的字段与 Yomitan 的标记（markers）对应起来，常用标记如：

| 标记 | 内容 |
| ---- | ---- |
| `{expression}` | 查询的单词 |
| `{sentence}` | 查词时所在的句子 |
| `{glossary}` | 词典释义 |
| `{audio}` | 读音音频 |

配置完成后，在弹窗里找到目标词条，点击**加号图标**即可把「单词 + 例句 + 释义」一键写入 Anki。

> [!NOTE]
> 想省事的读者可以跳过本节：完全靠 mpvacious 在视频侧制卡、词义在 Anki 里手动补，也是可行的工作流。但如果你大量阅读网页，这套联动值得配一次。

## 常见问题

- **弹窗不出来**：先检查是否已导入至少一本词典（见[词典管理](#词典管理)）；再检查页面是否处于「禁用扫描」状态（工具栏图标可切换全局/站点开关）。
- **扫描键和浏览器/其他扩展冲突**：在扫描设置里换一个触发键。
- **某些站点完全不弹**：少数站点对扩展脚本做了限制，或框架结构特殊，换个页面验证。
