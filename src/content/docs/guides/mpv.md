mpv 是一个自由开源的命令行风格播放器：没有花哨的界面，全键盘操作，资源占用极低，并且可以通过脚本无限扩展。对语言学习者来说，它有两大优势：

- **字幕与播放控制极精细**：逐句跳转、变速、字幕微调、双语字幕……都是为「看懂每一句」设计的；
- **可扩展**：下一篇要讲的 [mpvacious](/guides/mpvacious/) 就是以 mpv 插件的形式实现「边看边制卡」。

## 安装

| 系统 | 方式 |
| ---- | ---- |
| Windows | 从 [mpv.io](https://mpv.io/installation/) 下载安装包；推荐 shinchiro 构建（后续 mpvacious 也推荐此构建）。也可用 `scoop install mpv` |
| macOS | `brew install mpv` |
| Linux | 发行版包管理器安装，如 `sudo pacman -S mpv` / `sudo apt install mpv` |

验证安装：

```sh
mpv --version
```

## 基本用法

```sh
mpv video.mkv              # 播放文件
mpv ~/Videos/series/       # 播放整个文件夹（形成播放列表）
mpv 'https://www.youtube.com/watch?v=...'  # 播放网络视频
```

也可以直接把文件**拖放**到 mpv 窗口上。

> [!TIP]
> 播放 YouTube 等网络视频需要系统里装有 [yt-dlp](https://github.com/yt-dlp/yt-dlp)。装好后 `mpv 链接` 即可，还能用 mpv 的全部字幕与快捷键功能。

## 常用快捷键

以下全部是 mpv 官方默认键位（来自 `etc/input.conf`）。想测试某个键？运行 `mpv --input-test --force-window --idle`，按下的键会显示在屏幕上。

### 播放控制

| 键 | 功能 |
| ---- | ---- |
| `Space` / `p` | 播放 / 暂停 |
| `.` / `,` | 前进 / 后退一帧（自动进入暂停） |
| `q` | 退出 |
| `Q` | 退出并记住播放位置，下次接着看 |
| `f` | 全屏切换 |
| `T` | 窗口置顶 |

### 跳转

| 键 | 功能 |
| ---- | ---- |
| `←` / `→` | 后退 / 前进 5 秒 |
| `Shift+←` / `Shift+→` | 精确后退 / 前进 1 秒 |
| `↑` / `↓` | 后退 / 前进 1 分钟 |
| `Shift+↑` / `Shift+↓` | 精确后退 / 前进 5 秒 |
| `Ctrl+←` / `Ctrl+→` | **跳到上一句 / 下一句字幕** |
| `Home` | 回到开头 |

### 播放速度

| 键 | 功能 |
| ---- | ---- |
| `[` / `]` | 速度减 / 增 10% |
| `{` / `}` | 速度减半 / 加倍 |
| `Backspace` | 恢复 1.0x |

### 音量与音轨

| 键 | 功能 |
| ---- | ---- |
| `9` / `0`（或 `/` `*`） | 音量减 / 增 |
| `m` | 静音 |
| `#` | 切换音轨 |

### 字幕

| 键 | 功能 |
| ---- | ---- |
| `j` / `J` | 切换字幕轨（正向 / 反向） |
| `z` / `Z` | 字幕提前 / 延后 0.1 秒 |
| `v` | 显示 / 隐藏字幕 |
| `G` / `F` | 字幕字号增大 / 减小（注意大写！小写 `f` 是全屏） |
| `r` / `R`、`t` | 字幕位置上移 / 下移 |

### 截图与循环

| 键 | 功能 |
| ---- | ---- |
| `s` | 截图（原始分辨率，**含字幕**） |
| `S` | 截图（原始分辨率，不含字幕） |
| `Ctrl+s` | 按窗口所见截图（含界面与字幕） |
| `l` | 设置 / 清除 A-B 循环点（按两次设 A、B，再按清除） |
| `L` | 当前文件无限循环 |

## 语言学习场景

### 加载字幕

- 字幕文件与视频**同名**且放在同一目录，mpv 自动加载（`movie.mkv` + `movie.eng.srt`）。
- 手动加载：`mpv video.mkv --sub-file=subs.eng.srt`，或播放中把字幕文件拖进窗口。
- 字幕文件名与视频不完全一致？在配置里设 `sub-auto=fuzzy` 可以模糊匹配。
- 播放中可用菜单选择字幕轨：`g` 然后 `s`（`g-s` 打开字幕选择菜单）。

### 双语字幕（次字幕）

mpv 支持同时显示两条字幕轨：主字幕显示在底部，**次字幕显示在画面顶部**。

```sh
mpv video.mkv --secondary-sid=auto --slang=eng
```

播放中可用 `Alt+v` 切换次字幕显示。想要「英语主字幕 + 母语参考字幕」时非常实用（mpvacious 也支持把次字幕写进卡片，见下一篇）。

### 逐句精听

一套组合拳，专治「这句话没听清」：

1. `Ctrl+←` 跳回上一句字幕；
2. 听不清就 `[` 降速到 0.8x 左右；
3. 还不行 `.` `,` 逐帧对口型，`z`/`Z` 微调字幕对齐；
4. 搞懂后 `Backspace` 恢复原速。

### A-B 循环磨耳朵

在难句开头按一次 `l`，结尾再按一次 `l`，区间开始循环；听完按 `l` 清除。

## 配置文件入门

mpv 的两个核心配置文件（不存在就新建）：

| 系统 | 位置 |
| ---- | ---- |
| Linux / macOS | `~/.config/mpv/` |
| Windows | `C:/Users/用户名/AppData/Roaming/mpv/` |

`mpv.conf`——全局播放设置，一个适合语言学习的示例：

```ini
# 默认音量
volume=100
# 模糊匹配同目录字幕文件
sub-auto=fuzzy
# 默认优先选择的字幕语言（英语字幕优先）
slang=eng,en
# 默认优先选择的音轨
alang=eng
```

`input.conf`——自定义键位。示例（给字幕微调加个 50ms 精度的档位，挖句时更好用）：

```ini
# 字幕提前/延后 50ms
Z add sub-delay +0.05
z add sub-delay -0.05
```

> [!NOTE]
> 如果之后安装 mpvacious，注意它会占用 `H`、`L` 等键（用于逐句跳转），届时以 mpvacious 的键位为准。

mpv 本身只是播放器，真正的生产力来自它的脚本生态。下一篇：[mpvacious——边看视频边做 Anki 卡](/guides/mpvacious/)。
