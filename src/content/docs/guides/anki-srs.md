Anki 是这套工具链的核心：后面用 Yomitan 和 mpvacious 制作的生词卡都会存进 Anki，由它的算法安排复习时间。

这篇先讲原理，再给出一套推荐设置。

## 为什么需要间隔重复

一个多世纪前，心理学家艾宾浩斯（Ebbinghaus）通过实验得出了**遗忘曲线**：如果不复习，新学的知识会在几天内快速遗忘（指数级衰减）。

对抗遗忘有两个有效手段：

1. **主动回忆（Active Recall）**：强迫自己从记忆中提取答案，而不是反复阅读笔记。提取这个动作本身就能强化记忆。这就是「看句子回忆含义」比「反复念单词表」效果好的原因。
2. **间隔重复（Spaced Repetition）**：在快要忘记的时间点复习，效果最好。成功回忆后，下次复习的间隔会成倍延长。

SRS（Spaced Repetition System，间隔重复系统）就是实现这个原理的软件：算法计算最佳复习时间点，你只需要在看到卡片时如实反馈记没记住。Anki 现在默认的调度算法是 FSRS，它会根据你的复习记录为每张卡安排间隔。算法细节本文不展开，文末附有原始论文。

## Anki 核心概念

| 概念 | 英文 | 说明 |
| ---- | ---- | ---- |
| 牌组 | Deck | 卡片的集合，比如专门建一个「英语挖句」牌组。 |
| 笔记 | Note | 一条原始数据，比如「一句台词 + 截图 + 读音」。 |
| 字段 | Field | 笔记里的填空项，比如正面填句子，背面填释义。 |
| 笔记类型 | Note Type | 定义笔记有哪些字段、卡片长什么样的模板。 |
| 卡片 | Card | Anki 实际拿来考你的单位。 |
| 标签 | Tag | 用于搜索和归类。 |

**最容易搞混的是「笔记」和「卡片」**：一条笔记可以按模板生成多张卡片（比如一张考听力、一张考阅读）。

在用视频挖句的工作流里，通常一条笔记对应一张卡片。

## 日常复习流程

每天复习时，Anki 会展示卡片正面。你先回忆，再翻面，然后根据回忆的难易程度在四个按钮中选一个：

| 按钮 | 含义 |
| ---- | ---- |
| 重来（Again） | 完全没想起来，稍后会再次出现。 |
| 困难（Hard） | 想起来了，但花了较长时间。 |
| 良好（Good） | 正常想起。 |
| 简单（Easy） | 不假思索，立刻想起。 |

**评分要诚实。** 使用 FSRS 后，如实反映回忆难度即可，算法会据此安排间隔，不要去算计哪个按钮会让卡片更早或更晚出现。

## 推荐设置

打开牌组旁的齿轮，进入牌组选项（Deck Options）：

- **确保 FSRS 已开启**（新版本默认开启）。如果已复习过几百张卡，点一下「计算最佳参数」。
- **期望记忆率（Desired Retention）**：默认 0.9，即复习时约 90% 的卡片能回忆起来。如果负担太重，可以降到 0.85，代价是忘得多一些。
- **每日新卡数**：建议 10–20 张起步，按每天挖句的数量调整。
- **每日复习上限**：建议 200 左右，防止某天中断复习后第二天堆积过多。

:::caution
**积压是放弃 Anki 的最常见原因。** 宁可每天少加新卡，也不要让到期复习堆到四位数。一旦欠下大量未复习的卡片，很容易因挫败感而放弃。
:::

## 卡片制作建议

几条原则（源自 SuperMemo 的「最小信息原则」）：

1. **一张卡只考一件事**。正面塞多个问题会显著增加复习负担。
2. **带上上下文**。`He was reluctant to admit his mistake.` 比 `reluctant = 不情愿的` 更好记。
3. **卡片要短**。正面最好一眼能看完，大段文本会拖慢复习。
4. **多用图片和声音**。音频能练辨音，视频截图能还原看剧时的语境。后面用 mpvacious 抓句子时，这些媒体文件会自动带上。

典型的挖句卡片结构：

- **正面**：例句（生词加粗或挖空）
- **背面**：生词释义、音频、视频截图

### 笔记类型（模板）

**笔记类型（Note Type）**规定了笔记有哪些**字段**，以及卡片正反面如何呈现这些字段。Anki 自带的 Basic 模板只有正反两个文本字段，挖句不够用——句子、生词、释义、音频、截图需要各自的字段，也需要合理的排版。

这些不需要自己做，装一个现成的模板即可。

### 安装 Lapis 模板

[Lapis](https://github.com/donkuri/lapis) 是社区里最主流的挖句笔记类型之一，出自 [donkuri](https://github.com/donkuri) 团队，轻量、开箱即用：

- **词典兼容性好**：不依赖 Yomitan 的自定义模板语法，各家词典的内容都能正常排版；
- **考法丰富**：单词卡、整句卡、点击出句子的「点击卡」、考听力的「音频卡」，往对应的 `Is...Card` 字段填 `x` 即可切换；
- **细节到位**：支持注音与音调显示，点击释义区左右边缘可翻看更多词典；
- **易于定制**：字号、字体、加粗颜色都提取成了 CSS 变量，照着注释改数值即可。

:::note
Lapis 为日语挖句设计，但字段是通用的，挖英语等其他语言的句子也没问题。
:::

**安装步骤：**

1. 打开 [Lapis 的最新 Release](https://github.com/donkuri/lapis/releases/latest)（写作时为 v1.7.0），下载其中的 `.apkg` 文件——一册带示例卡的牌组；
2. 双击该文件，或在 Anki 里走 `文件` → `导入`，按默认设置导入（建议 Anki 23.10 及以上版本）；
3. 导入完成后，Anki 里会多出一个名为 `Lapis` 的笔记类型。示例牌组看完即可删除，笔记类型会保留。

:::tip
Lapis 出新版后，重新导入新的 `.apkg` 即可升级。注意升级会把卡片样式重置回默认，自定义过样式的话，先把改动记下来，升级后再改回去。

[Yomitan](/guides/yomitan/) 和 [mpvacious](/guides/mpv/) 分别往 Lapis 的哪些字段写数据，到各自的篇章再细说。
:::

## 安装 AnkiConnect

**AnkiConnect** 是一个本地服务插件，让浏览器和播放器可以直接把卡片写入 Anki。Yomitan 和 mpvacious 都依赖它。

**安装**：在 Anki 菜单栏点击 `工具` → `插件` → `获取插件`，输入代码 **2055492159**，安装后重启 Anki。

:::note
在电脑上用工具制卡时，**必须保持 Anki 处于打开状态**，。
:::

## 避坑指南

- **囤积共享牌组**：收藏不等于学会，不进入复习流程的卡片没有价值。
- **长文卡**：整段文章贴进卡片，复习时大概率直接跳过。
- **突击加卡**：一天加 100 张新卡，两周后被复习量压垮。
