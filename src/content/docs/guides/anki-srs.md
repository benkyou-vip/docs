Anki 是整个工具链的「记忆中枢」：Yomitan 和 mpvacious 制作的卡片最终都汇入 Anki，由它的调度算法安排复习。这篇先讲清楚原理，再给出一套能直接上手的配置。

## 为什么需要间隔重复

心理学家艾宾浩斯（Ebbinghaus）在 19 世纪的实验揭示了**遗忘曲线**：不复习的话，新记忆在几天内就会大量流失，且衰减是指数式的。

对抗遗忘有两个关键手段：

1. **主动回忆（Active Recall）**：不是重读笔记，而是*尝试从记忆里提取答案*。提取这个动作本身就会强化记忆——这正是「看句子正面、回想词义」比「反复浏览单词表」有效得多的原因。
2. **间隔重复（Spaced Repetition）**：在「即将遗忘」的临界点复习，然后用更长的间隔再次复习。每次成功回忆后，记忆的保质期都会成倍延长。

SRS（Spaced Repetition System）就是自动完成这个调度的系统：你只管评分「记没记住」，间隔由算法计算。

## 调度算法：从 SM-2 到 FSRS

### SM-2

Anki 长期使用的经典算法，源自 1987 年 SuperMemo 的 SM-2。思路：每张卡有一个** Ease Factor（简易度）**和**间隔**，评分好则间隔乘上一个系数增长。缺点是参数较粗糙，对「复习拖延」「中途弃坑」等情况不友好，容易出现间隔爆炸或雪崩。

### FSRS

FSRS（Free Spaced Repetition Scheduler）是新一代开源算法，基于记忆研究中的「难度—稳定性—可提取性」三变量对每张卡建模：

- **难度（D）**：这张卡对你有多难
- **稳定性（S）**：当前记忆能维持多久
- **可提取性（R）**：此刻你能回忆起来的概率

Anki 从 23.10 版本起内置 FSRS，新版本已默认启用。它会根据**你自己的复习记录**计算个性化参数（所谓「训练」），预测精度显著优于 SM-2。

> [!TIP]
> 如果你从旧版本迁移而来：在牌组选项中确认 FSRS 已开启，并点「计算最佳参数」。积累几百条复习记录后重新计算一次，参数会更贴合你的实际水平。

## Anki 核心概念

| 概念 | 英文 | 说明 |
| ---- | ---- | ---- |
| 牌组 | Deck | 卡片的容器，对应你的某门语言或某类内容 |
| 笔记 | Note | 一条信息记录，如「一个例句 + 词义 + 音频」 |
| 笔记类型 | Note Type | 笔记的字段结构和卡片模板的定义 |
| 字段 | Field | 笔记里的一个个数据格，如 Sentence、Audio |
| 卡片模板 | Card Template | 定义如何把字段渲染成正面/背面 |
| 标签 | Tag | 给笔记打标记，便于筛选管理 |

最容易混淆的是**笔记和卡片**：一条笔记（一个句子）可以按模板生成一张或多张卡片（正面句子猜词义、正面听音频猜句子……）。挖句工作流通常一笔记一卡即可。

## 日常复习长什么样

复习时 Anki 展示卡片正面，你主动回想后翻面，然后按四个按钮之一评分：

| 按钮 | 含义 |
| ---- | ---- |
| 重来（Again） | 没想起来，很快会再出现 |
| 困难（Hard） | 想起来了，但很吃力 |
| 良好（Good） | 正常想起 |
| 简单（Easy） | 秒答且确定 |

使用 FSRS 时，评分如实反映回忆难度即可，间隔由算法统一决定，不必纠结每档按钮的后果。

## 推荐设置

在牌组选项（Deck Options）里：

- **开启 FSRS**（新版本默认开启），并计算最佳参数。
- **期望记忆率（Desired Retention）**：默认 0.9，表示目标是复习时有 90% 的卡片能想起。追求长期留存的读者可保持默认；觉得复习量太大可以降到 0.85，代价是忘得稍多。
- **每日新卡数**：10–20 张起步。句子挖掘阶段产多少卡、加多少新卡，量力而行。
- **每日复习上限**：200 左右，防止偶尔的积压压垮你。

> [!IMPORTANT]
> Anki 最怕积压。宁可少加新卡，也不要让到期复习堆到四位数——一旦「还债」心态出现，弃坑就不远了。

## 卡片设计原则

来自 SuperMemo「最小信息原则」的几条实用守则：

1. **一张卡只考一个知识点**。正面塞三个问题，等于每次复习都在做多项任务。
2. **句子优先于孤立单词**。`He was reluctant to admit his mistake.` 比 `reluctant = 不情愿的` 好记得多。
3. **卡片要短**。正面一眼能读完，长段文本是复习效率杀手。
4. **利用多媒体**。音频练听力辨认，截图唤起语境记忆——mpvacious 制卡时会自动附上。

典型的挖句卡片结构：

- **正面**：例句（生词加粗或挖空）
- **背面**：生词释义、音频、视频截图

### 建一个挖句用的笔记类型

后续 [Yomitan](/guides/yomitan/) 和 [mpvacious](/guides/mpvacious/) 都会往 Anki 写卡片，提前准备好字段。推荐字段：

| 字段 | 内容 | 来源 |
| ---- | ---- | ---- |
| Sentence | 例句 | mpvacious / Yomitan |
| Word | 生词 | Yomitan |
| Definition | 词义 | Yomitan |
| Audio | 句子音频 | mpvacious |
| Image | 视频截图 | mpvacious |

> [!TIP]
> 不想手动建字段的话，mpvacious 官方提供了一个现成的笔记类型（[AnkiWeb #1557722832](https://ankiweb.net/shared/info/1557722832)），导入即可用。

## AnkiConnect

**AnkiConnect** 是 Anki 的一个插件，在本机开一个 HTTP 接口（端口 8765），让外部程序能增删卡片——Yomitan 加词卡、mpvacious 制卡全靠它，堪称「给其他工具开门」。

安装：Anki 菜单 → 工具 → 插件 → 获取插件，输入代码 **2055492159**，重启 Anki。

> [!NOTE]
> Yomitan 和 mpvacious 只在**桌面版 Anki 正在运行**时才能写卡。手机端 Anki 仅用于复习，不影响。

## 常见误区

- **囤卡成瘾**：收藏 ≠ 学会。卡片必须进入复习流程才有价值。
- **卡片过重**：把整段课文贴进卡片，复习时直接跳过。
- **新卡猛加**：热情高涨时一天加 100 张，两周后被复习量劝退。
- **评分作弊**：明明没想起来却按「良好」，算法会被你的谎言带偏。
