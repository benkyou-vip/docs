## 为什么选择沉浸式学习

传统外语课堂以「讲解 + 练习」为主：先学语法规则，再做填空选择题。这种方式培养的是*关于语言的知识*，而不是*使用语言的能力*——很多人学了十年英语，依然听不懂无字幕美剧、读不下去原版小说。

沉浸式学习的思路相反：

- **大量接触真实内容**。把美剧、YouTube、播客、小说当作学习的主体，而不是教材的补充。
- **在语境中自然习得**。语言学中的「输入假说」（Krashen 的 comprehensible input，即可理解输入）认为：当输入内容略高于当前水平（即 *i+1*）时，语言能力会自然提升。
- **先输入，后输出**。先花大量时间听和读，储备足够语料之后，再说和写。

## Refold 是什么

[Refold](https://refold.la) 是从 AJATT（All Japanese All The Time）社区发展出来的一套学习路线图，最初为日语设计，但适用于任何语言。它回答的核心问题是：

> 从零基础到接近母语水平，每个阶段该做什么、做多少？

Refold 的核心是反复做三件事：

1. **沉浸**：每天看、听真实的母语内容。
2. **句子挖掘**：在看剧或阅读时，把带有生词的句子摘出来，做成记忆卡。
3. **间隔重复（SRS）**：用算法把卡片安排进每天的复习，把短期记忆变成长期记忆。

本系列后续介绍的所有软件，都是为了让这三步尽可能高效。

## 核心概念

### 精读 vs 泛读

沉浸分为泛读（泛听）和精读（精听）。

常见的错误是全程精读：每遇到一个生词都暂停查词典、反复重听不懂的句子，既累又慢，很难坚持。

健康的节奏是：**泛读为主（80% 以上）**，只求大意，靠数量培养语感、巩固已认识的词；**精读为辅**，每天挑出少量难点句子，逐字弄懂并做成卡片，用来扩展新词汇。

### 句子挖掘

不要背单词书里的孤立词条。每天沉浸时，挑出「只有一个生词」的句子（正好符合 *i+1* 的难度），做成 Anki 卡片。句子来自刚看过的剧情或语境，有上下文支撑，记忆更牢固。

后续要讲的 [mpvacious](/guides/mpv/) 和 [Yomitan](/guides/yomitan/)，就是为了把「制卡」自动化。

### 间隔重复

对新信息的遗忘呈指数式，在「快要忘记」的临界点复习，效果最好。SRS（Spaced Repetition System）算法负责计算这个临界点。详见 [Anki 与 SRS](/guides/anki-srs/)。

## 路线图各阶段

Refold 将学习过程划分为五个阶段：

### 阶段 0：准备

- 学目标语言的发音系统。英语为例：国际音标、常见连读/弱读现象，确保「看到音标能读出来、听到音能大致写出来」。
- 装好工具：Anki、浏览器 + Yomitan、mpv。也就是本系列的四篇工具文档。

### 阶段 1：基础

- 学最高频的 1000–2000 个词（覆盖日常语料 80% 以上）和基础语法。
- 不必「学完再沉浸」：从第一天起就配合简单内容泛听，听不懂多少也没关系。
- 这个阶段的生词主要来自词表或入门教材，用 Anki 记。

### 阶段 2：沉浸加速

**本系列工具链的主要应用阶段。**

- 每天投入大块时间（1–3 小时以上）沉浸真实内容：看剧、看视频、听播客、读分级读物。
- 正式开始句子挖掘：每天从沉浸内容里产出 10–20 张卡。
- 遇到生词用 Yomitan 秒查，看视频时用 mpvacious 一键制卡。

### 阶段 3：输出

- 开始大量开口说、动笔写（找语伴、自言自语、写日记）。
- 输出会暴露薄弱点，反过来指导沉浸素材的选择。
- 输入不能停，仍然是每天的主体。

### 阶段 4：精进

- 消化更难的内容：纪录片、专业领域材料、文学原著。
- 补齐残余弱点：口音细节、生僻词汇、文化背景。
- 到这一步，学习方法已经和母语者自我提升的方式没有本质区别。

## 工具与阶段的对应

| 阶段 | 主要活动 | 用到的工具 |
| ---- | ---- | ---- |
| 0 | 发音入门、装工具 | 全部安装一遍 |
| 1 | 高频词 + 基础语法 | Anki |
| 2 | 大量沉浸 + 句子挖掘 | mpv、Yomitan、mpvacious、Anki |
| 3 | 输出练习 + 持续输入 | mpv、Yomitan、mpvacious、Anki |
| 4 | 高难度内容 | 同上 |

环境搭好后，每天的学习流程如下：

```text
用 mpv 看剧（带外文字幕）
  → 遇到生词：按 Ctrl+h 退回那句台词，用 mpvacious 一键生成带有句子、音频和截图的 Anki 卡片
  → 用 Yomitan 查词义，补充到卡片里
  → 第二天打开 Anki，复习昨天新增的词
```

## 英语学习素材建议

选材的唯一标准：**你自己感兴趣，而且能大致看懂七八成**。梯度参考：

- **入门**：ESL 教学频道、vlog、动画（用语简单、语速友好）
- **进阶**：情景喜剧（Friends、Modern Family 等日常对话密集）、YouTube 频道、播客
- **高级**：纪录片、脱口秀、有声书、原版小说

:::tip
材料难度不是越难越好。太难的内容需要频繁暂停、查词，不适合泛听；「能不暂停地看懂大意」的材料才是泛听素材，更难的留给精听。
:::

:::note
本系列以**英语**为目标语言，但 Refold 方法与整套工具链对其他语言同样适用。换语言时主要变化是**词典**（例如日语换用日语词典）和**素材**，详见 [Yomitan 一篇的词典章节](/guides/yomitan/#词典管理)。
:::
