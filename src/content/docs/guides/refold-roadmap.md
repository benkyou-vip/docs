在动手装任何软件之前，先花十分钟搞清楚「方法论」。工具是拿来落实方法的，方法不清，工具就只是一堆零散的软件。

## 为什么选择沉浸式学习

传统的外语课堂以「讲解 + 练习」为主：先学语法规则，再做填空选择题。这种方式培养的是*关于语言的知识*，而不是*使用语言的能力*——很多人学了十年英语，依然听不懂无字幕美剧、读不下去原版小说。

沉浸式学习（Immersion Learning）的思路恰好相反：

- **大量接触真实内容**。把美剧、YouTube、播客、小说当作学习的主体，而不是教材的补充。
- **在语境中自然习得**。语言学中的「输入假说」（Krashen 的 comprehensible input，即可理解输入）认为：当输入内容略高于当前水平（即 *i+1*）时，语言能力会自然生长，就像儿童习得母语一样。
- **先输入，后输出**。先花大量时间听和读，储备足够语料之后，再说和写。

## Refold 是什么

[Refold](https://refold.la) 是从 AJATT（All Japanese All The Time）社区发展出来的一套学习路线图，最初为日语设计，但其框架适用于任何语言。它回答的核心问题是：

> 从零基础到接近母语水平，每个阶段该做什么、做多少？

Refold 的方法可以浓缩为三件事：

1. **沉浸（Immersion）**——每天用目标语言大量听、读真实内容。
2. **句子挖掘（Sentence Mining）**——从沉浸内容中挑出含有生词的句子，做成记忆卡。
3. **间隔重复（SRS）**——用算法安排这些卡片的复习时间，把生词固化成长期记忆。

本系列后面的四篇工具文档，分别对应这三件事的不同环节。

## 核心概念

### 精读 vs 泛读

沉浸分两种模式，需要搭配使用：

| 模式 | 做法 | 目的 |
| ---- | ---- | ---- |
| 精读 / 精听（intensive） | 逐句弄懂，查每一个生词，反复听难句 | 攻坚、扩展词汇 |
| 泛读 / 泛听（extensive） | 追求大意，不求甚解，量大为王 | 培养语感、巩固已知 |

初学者容易全程精读，结果又累又慢。健康的节奏是：**泛读占大头（80% 以上），每天挑出少量句子精读并制成卡片**。

### 句子挖掘

从今天看的内容里，挑出「只含一个未知知识点」的句子（正好是 *i+1*），做成 Anki 卡片。因为句子来自你真实看过的语境，记忆效率远高于背单词书里的孤立词条。这正是 [mpvacious](/guides/mpvacious/) 和 [Yomitan](/guides/yomitan/) 要自动化的事情。

### 间隔重复

人脑对新信息的遗忘是指数式的，而在「快要忘记」的临界点复习，记忆效果最好。SRS（Spaced Repetition System）算法负责计算这个临界点。详见 [Anki 与 SRS](/guides/anki-srs/)。

## 路线图各阶段

Refold 把学习过程划分为阶段 0 到阶段 4（以下为目标概括，非官方译名）：

### 阶段 0：准备

- 学目标语言的发音系统。英语为例：国际音标、常见连读/弱读现象，确保「看到音标能读出来、听到音能大致写出来」。
- 装好工具：Anki、浏览器 + Yomitan、mpv。也就是本系列的四篇工具文档。

### 阶段 1：打地基

- 学最高频的 1000–2000 个词（覆盖日常语料 80% 以上）和基础语法。
- 不必追求「学完再沉浸」：从第一天起就配合简单内容的泛听，哪怕听不懂多少。
- 这个阶段的生词主要来自词表或入门教材，用 Anki 记。

### 阶段 2：沉浸加速

**本系列工具链的主战场。**

- 每天保证大块时间（1–3 小时以上）沉浸在真实内容里：看剧、看视频、听播客、读分级读物。
- 正式开始句子挖掘：每天从沉浸内容里产出 10–20 张卡。
- 遇到生词用 Yomitan 秒查，看视频时用 mpvacious 一键制卡。

### 阶段 3：输出

- 开始大量开口说、动笔写（找语伴、自言自语、写日记）。
- 输出会暴露短板，反过来指导你选沉浸素材。
- 输入不能停，仍然是每天的主体。

### 阶段 4：精进

- 消化更难的内容：纪录片、专业领域材料、文学原著。
- 修补残余缺口：口音细节、生僻词汇、文化背景。
- 到这一步，学习方法已经和母语者自我提升的方式没有本质区别。

## 工具与阶段的对应

| 阶段 | 主要活动 | 用到的工具 |
| ---- | ---- | ---- |
| 0 | 发音入门、装工具 | 全部安装一遍 |
| 1 | 高频词 + 基础语法 | Anki |
| 2 | 大量沉浸 + 句子挖掘 | mpv、Yomitan、mpvacious、Anki |
| 3 | 输出练习 + 持续输入 | mpv、Yomitan、mpvacious、Anki |
| 4 | 高难度内容 | 同上 |

一个典型的日常闭环：

```
mpv 看剧（英语字幕）
  → 遇到生词句：Ctrl+h 回句首，mpvacious 一键制卡（句子 + 音频 + 截图进 Anki）
  → 同时用 Yomitan 查词义，补充到卡片或单独制词卡
  → 第二天在 Anki 里复习
```

## 英语学习素材建议

选材的唯一标准是**自己感兴趣且大致看得懂（七成左右）**。大致梯度供参考：

- **入门**：ESL 教学频道、vlog、动画（用语简单、语速友好）
- **进阶**：情景喜剧（Friends、Modern Family 等日常对话密集）、YouTube 频道、播客
- **高级**：纪录片、脱口秀、有声书、原版小说

> [!TIP]
> 材料难度不是越难越好。太难的内容会让你频繁暂停、查词，沉浸就变成了苦役；「能不暂停地看懂大意」的材料才是泛听素材，难一点留给精听。

> [!NOTE]
> 本系列以**英语**为目标语言，但 Refold 方法与整套工具链对其他语言同样适用。换语言时主要变化是**词典**（例如日语换用日语词典）和**素材**，详见 [Yomitan 一篇的词典章节](/guides/yomitan/#词典管理)。
