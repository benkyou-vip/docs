这套指南围绕一条完整的**沉浸式学习工作流**展开：方法上遵循 Refold 路线图，工具上以 Anki 为记忆中枢，Yomitan 负责秒查生词，mpv 负责精细的播放控制，mpvacious 则把「看视频」和「做卡片」缝合成一个动作。

## 日常闭环

熟练之后，你每天的沉浸学习长这样：

1. 用 **mpv** 打开带目标语言字幕的剧集，正常沉浸观看；
2. 遇到含生词的句子，**mpvacious** 一键把「句子 + 音频 + 截图」送进 Anki；
3. 生词释义用 **Yomitan** 秒查，顺手补进卡片；
4. 第二天在 **Anki** 里复习——间隔重复算法保证你在最该复习的时候复习。

从看剧到复习，全程不过多按几个键，沉浸节奏几乎不被打断。

> [!NOTE]
> 本系列以**英语**为目标语言演示，但方法与整套工具链适用于任何语言——换语言时主要更换**词典**与**素材**，详见 Yomitan 篇的词典管理章节。

## 适合谁

- 有一点基础、想脱离教材、用真实内容学语言的人；
- 愿意花一个下午配置工具，换取之后每天顺畅挖句的人；
- 任何想把「看过的内容」变成「记住的内容」的学习者。
