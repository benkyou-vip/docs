这套指南记录了如何使用 Anki、Yomitan 和 mpv 搭建一套高效的语言学习环境。

其核心思路是通过工具自动化，降低在阅读和观影时查词、制卡的摩擦力。

## 工作流

配置完成后，日常学习流程如下：

1. 使用 **mpv** 播放带有目标语言字幕的视频；
2. 遇到生词时，通过 **mpvacious** 快捷键截取当前字幕、音频和画面，直接发送至 Anki；
3. 使用 **Yomitan** 快速查询词义，并补充到卡片中；
4. 在 **Anki** 中根据间隔重复算法复习。

:::note
本文档以英语学习为例。但该工具链适用于大多数语言，切换语言时只需更换相应词典和素材即可，详见 Yomitan 配置章节。
:::
